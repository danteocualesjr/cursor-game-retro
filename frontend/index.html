Welcome to Codequest!

You write tiny lines of code to guide the hero through pixel puzzles. Try things, mess up, try again.

  1. Type code in the editor. Start typing mo to see suggestions.
  2. Click RUN (or press Ctrl/Cmd + Enter) to watch the hero follow your code.
  3. Stuck? Click HINT and Hoot the Owl - a real AI tutor - will nudge you with a small clue (never the full answer).
  4. STOP a long run with the red button or Esc. RESET rebuilds the level.
  5. Solve a level in few enough steps to earn 3 stars. Replay to chase a better score.
